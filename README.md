# Credit-Card-Financial-Dashboard-Power-BI-SQL-DAX-Excel

**Credit Card Financial Dashboard | Power BI, SQL, DAX, Excel**

- Developed interactive Power BI dashboards to analyze credit card transactions, customer demographics, revenue, interest earnings, and transaction trends.
- Used SQL (PostgreSQL) to create database tables, import customer and transaction datasets, and prepare data for analysis.
- Implemented DAX measures and calculated columns to track key performance indicators (KPIs), weekly revenue changes, customer segments, card-category performance, and activation and delinquency rates.
- Visualized financial trends through interactive charts, KPI cards, and filters to support data-driven business insights.
